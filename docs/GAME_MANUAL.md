> `<!-- AUTO:... -->` 안의 표는 `python tools/make_manual.py`가 `include/economy_data.h`에서 다시 만든다. 표를 손으로 고치지 말고 데이터 파일을 고친 뒤 스크립트를 돌린다.

## 1. 개요
| 항목 | 내용 |
|---|---|
| 제목 | **HookedSmith** (GBA, Butano 21.8.0 / C++) |
| 한 줄 소개 | 가문의 명예를 위한 대장장이 스미스.. (문구 다듬는 중) |
| 모티브 | 플래시 게임 「검 강화하기」 |
| 목표 | 낡은 단검을 **+29 검**까지 강화한다. +29 달성이 엔딩 (엔딩 연출은 아직 없음) |
| 핵심 루프 | 돈으로 강화 → 성공하면 단계 상승 → 적당한 단계에서 판매해 돈을 번다 → 실패하면 파괴되고 잡템을 얻는다 → 잡템을 방지권·검으로 바꾼다 |
| 화면 흐름 | 스플래시 → 타이틀 → 강화 화면 ⇄ 상점(L) / 화구(R) / 창고(←) / 잡화(↓) |

## 4. 규칙

|---|---|
| 화폐 | 정수 달러($) |
| 강화 | 비용을 내고 성공률로 +1. 실패하면 검 파괴 → +0 복귀, 잡템 드랍 |

| 기능 | 키 | 동작 |
|---|---|---|
| 강화 | A | 망치 |
| 판매 | B | 지폐 |
| 상점 | L | +0 검일 때만 사용 가능 |

| 창고 | ← | 보관한 검 목록. A 꺼내기 = 현재 검과 맞바꿈 (현재가 +0이면 버림), R 현재 검 보관 |
| 잡화 | ↓ | 잡템 목록 (보기만) |
| 도움말 | SELECT | 누르고 있는 버튼의 설명 표시 |

### 강화 실패 연출 (구현됨, 화면 확인 완료)
- 실패하면 검이 좌우로 떨리다가 **절반쯤에서 오른쪽 위→왼쪽 아래로 지그재그 금이 가고 번쩍인다** (빠직).
- **방지권을 쓰는 경우:** 금 간 검 그대로 질문이 뜨고, A(쓴다)를 누르면 금이 사라지며 번쩍이고 원래 검으로 돌아온다.
- **부서지는 경우(방지권 없음 또는 안 씀):** 검이 금 간 선을 따라 **두 동강**이 나 위쪽 조각은 왼쪽 위로, 아래쪽 조각은 아래로 돌며 떨어지고, **작은 파편 4개**가 튄다. 그 뒤 +0 검과 파괴 메시지(잡템)가 나온다.
- 조각 그림은 `tools/make_swords.py`가 검 그림에서 자동으로 만든다 (검 그림을 바꿔도 따라감). 한 장에 프레임 4개(원래·금·위 조각·아래 조각), 파편은 `graphics/shard.bmp`.
- 시간(프레임): 떨림 24(금은 12프레임째), 복구 16, 부서짐 36. `main.cpp`의 `crack_frame` 등.
- 디버그 빌드: 강화 화면에서 +1 이상일 때 R을 누르면 "다음 강화 무조건 실패" 스위치가 켜지고 꺼진다.

## 12. 스토리 (기획)
- 왕이 "+29 검 = 평생 세금 면제" 포고문을 건다.
- 랜덤 이벤트(도둑, 세금 징수관, 수상한 상인, 고양이, 라이벌 대장장이)는 4단계 이후.
- 엔딩: 왕이 너무 무거운 +29 검에 깔리고, 마을 사람들이 냄비와 괭이를 들고 "우리 것도 +29 해주게" 줄을 서며, 마지막에 타이틀.
- 진행 구간(임시): +0~5 동네 대장간 / +6~10 소문 / +11~15 왕의 눈 / +16~20 전설 / +21~29 재료 강화.
- 오프닝 컷씬: `src/main.cpp`의 `opening_scenes`. 하드 엔딩은 미정.
- **엔딩 연출은 플레이 시각의 시간대(낮/노을/밤)에 따라 다르게 한다** (14번과 같은 시간대). 시나리오는 추후 기획. 시계가 없으면 낮 버전.

## 14. 시간대 (RTC)
### 14-1. 타이틀 그림 (구현됨)
카트리지 RTC 시계로 타이틀 배경을 바꾼다. 시계가 없거나 읽지 못하면 낮 그림.
| 시간대 | 시각 | 상태 |
|---|---|---|
| 낮 | 06~16시 | 확정 (2026-10-16) |
| 노을 | 16~21시 | 확정 |
| 밤 | 21~06시 | 확정 |

같은 시간대를 강화 확률 보정(14-2)에도 쓴다.

### 14-2. 시간대별 강화 확률 (구현됨)
RTC 시간대에 따라 **강화 성공률만** 조정한다. 판매가·비용·방지권은 그대로.
시간대는 타이틀과 같은 **낮 / 노을 / 밤** 3구간을 쓴다 (아침은 없앰).
| 시간대 | 성공률 보정 | 상태 |
|---|---|---|
| 낮 | 원작 그대로 (0%p) | 확정 |
| 노을 | -2%p | 확정 |
| 밤 | -4%p | 확정 |
- 시간대 경계는 14-1과 같다: 낮 06~16 / 노을 16~21 / 밤 21~06 (확정).
- **100% 구간(+0~+2 등)에도 적용한다.** 예: 노을에 +0은 98%, 밤에 96%.
- **하한 0%**: 보정 후 0% 아래로는 내리지 않는다.
- **HARD에도 같은 보정**을 쓴다.
- 시계가 없으면 보정 없음(원작 확률).
- **세이브와의 관계 (확정)**: 저장 파일에는 시간대 정보를 넣지 않는다. 강화할 때마다 **그 순간의 시계**로 확률을 계산한다. 낮에 저장한 것을 밤에 불러오면 밤 확률이 적용된다.
- 한 판을 하는 도중 시간대 경계(16시, 21시)를 넘으면 확률이 바로 바뀌고, 화면의 성공률 표시도 같이 바뀌어야 한다 (강화 화면에서 시계를 주기적으로 확인).
- 슬롯 목록에 저장 시각을 표시하는 것은 선택 사항이며 확률과 무관하다.
- 플레이어가 시계를 바꿔 시간대를 고르는 것은 **허용** (막지 않는다).

구현 메모
- 시간대 판정은 `include/time_band.h` / `src/time_band.cpp`(`hs::current_time_band()`)이고 타이틀 그림도 같은 함수를 쓴다. 보정은 `economy::success_pct()`가 적용하고 `upgrade()`가 그 값으로 판정한다.
- 강화 버튼을 누르는 순간 시계를 다시 읽고, 강화 화면에서는 1초마다 확인해 16시·21시·06시를 넘으면 성공률 표시가 바로 바뀐다.
- 화면의 "성공률 N%"는 보정된 값이다. 시간대 자체를 알려 주는 표시는 아직 없다.
- 실제 카트리지에 RTC 칩이 있어야 동작한다. mGBA는 설정(`[override.HKSM] hardware=1`)이 필요하다.

## 15. 일시정지 메뉴와 세이브 (구현됨)
강화 화면에서 START를 누르면 게임이 멈추고 메뉴가 뜬다. (`run_pause()`, `src/main.cpp`)
- **구현됨:** PAUSE 고정 글자, Resume / Save / Quit 선택(↑↓, 고른 줄이 위아래로 흔들림), Resume(START·B로도 재개), Quit(타이틀로), Save의 슬롯 3개 선택 화면.
- **Save:** 슬롯 3개 중 하나를 골라 저장한다 (`src/save.cpp`). 줄마다 "SLOT 1  STORY +3  $9.9K" 또는 "비어 있음"을 보여 준다. 이미 저장된 슬롯은 "덮어쓸까요? A 예 B 아니오"로 한 번 묻는다. 저장하면 "저장했다!".
- **불러오기 (시작 화면):** 타이틀에서 STORY 또는 HARD를 고르면 START 화면이 열리고 "NEW GAME"과 슬롯 3개가 나온다. NEW GAME을 고르면 새 게임(STORY만 오프닝 컷씬 후 시작, HARD는 바로 시작), 슬롯을 고르면 컷씬 없이 바로 강화 화면으로 간다. 빈 슬롯은 "비어 있는 슬롯이다". B는 타이틀로. STORY·HARD 어느 쪽으로 들어가도 같은 화면이고, 어떤 모드의 슬롯이든 불러올 수 있다 (미정: 모드별로 나눌지). **화면은 mGBA에서 아직 직접 확인하지 못했다.**
- **저장 항목:** 난이도, 소지금, 현재 검 단계, 방지권, 잡템 8종, 보관한 검(최대 8). 난수 시드는 저장하지 않고 불러온 시점의 프레임 수로 새로 정한다. 시간대는 저장하지 않는다 (14-2).
- **공통 머리글:** HARD 해금 플래그(`hs::save::hard_unlocked()`, 해금은 `unlock_hard()`로 나중에 엔딩에서 호출).
- **안전장치:** 슬롯마다 검사합과 값 검사가 있어서 깨지거나 처음 쓰는 카트리지의 슬롯은 빈 슬롯으로 본다. SRAM 32KB 중 약 200바이트를 쓴다.
- **미적용:** 강화 화면 외(상점·화구·창고·컷씬)에서는 START가 아직 동작하지 않는다.
- 일시정지 화면은 강화 화면을 덮는 별도 화면이고, 돌아오면 강화 화면이 다시 열린다.
| 항목 | 동작 |
|---|---|
| PAUSE | 제목 글자. 고정 (애니메이션 없음) |
| Resume | 게임을 재개한다 |
| Save | 현재 상황을 저장한다. 슬롯 3개 중 선택 |
| Quit | 메인 타이틀로 돌아간다 |
- Resume / Save / Quit은 ↑↓로 고르고, 고른 항목에 약간의 애니메이션(흔들림 등)이 붙는다. 타이틀 메뉴의 위아래 흔들림과 같은 방식을 쓸 수 있다.
- 디버그 빌드의 지원금 키는 START에서 **↑**로 옮겼다.
- 정해야 할 것: 저장 시 덮어쓰기 확인, Quit 시 저장 안 한 진행 경고, 어느 화면(상점·화구·창고·컷씬)에서도 START를 받을지.

## 17. 게임 오버 (구현됨)
파산 구제 장치는 **없다.** 아무것도 할 수 없는 상태가 되면 게임 오버.

파산 조건 (아래를 **모두** 만족할 때):
| 조건 | 설명 |
|---|---|
| 강화할 수 없음 | 돈이 현재 단계의 강화비보다 적다 (+0이면 STORY $3 / HARD $5). 재료 강화 단계는 재료가 없다 |
| 상점에서 살 수 없음 | 돈이 가장 싼 상품(워프 +9 HARD $8,000 / 방지권 STORY $10,000 등)보다 적다 |
| 화구에서 만들 수 없음 | 어떤 교환도 잡템 수량이 모자란다 |
| 팔 것이 없음 | 지금 검이 +0이고 창고에도 검이 없다 (검이 있으면 팔아서 돈을 만들 수 있다) |

흐름
1. 파산 판정이 되면 게임 오버 화면.
2. "아무 버튼이나 누르세요" 표시.
3. 아무 버튼을 누르면 타이틀로 간다.

구현 내용 (`economy::is_bankrupt()`, `run_game_over()`)
- 판정은 강화 화면이 평상시(IDLE) 상태일 때 하고, 판매·파괴 결과 메시지를 다 보여 준 뒤 게임 오버로 넘어간다. 상점·화구·창고에서 돌아와도 같다.
- 최종 검(+29)에서는 파산이 아니다.
- 화면: 일러스트(대장간 앞에 무릎 꿇은 스미스, GAME OVER 간판이 그림 안에 있음)와 깜빡이는 "아무 버튼이나 누르세요". 처음 약 0.75초는 입력을 받지 않는다. 아무 버튼을 누르면 타이틀로 간다. 그림은 `assets/graphics/gameover/gameover_source.jpg` → `tools/make_gameover.py`(수동 실행)로 `graphics/gameover_bg.bmp`를 만든다.
- **저장 슬롯은 건드리지 않는다** (마지막 저장부터 다시 불러올 수 있다).
- 방지권이 남아 있어도 위 조건이면 파산이다 (방지권은 돈을 만들지 못한다).
- 디버그 빌드: 강화 화면에서 B를 누른 채 ↑로 파산 상태를 만든다.
- 음악·효과음은 아직 없다.
