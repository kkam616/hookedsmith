# HookedSmith 게임 매뉴얼 (역기획 문서)

> 구현된 시스템을 기준으로 정리한 문서다. 시스템을 추가하거나 고칠 때 같이 고친다.
> `<!-- AUTO:... -->` 안의 표는 `python -B tools/make_manual.py`가 `include/economy_data.h`에서 다시 만든다. 표를 손으로 고치지 말고 데이터 파일을 고친 뒤 스크립트를 돌린다.
> 상태 표기: **확정** = 원작·기획으로 정해진 값, **임시** = 내가 정한 값(조정 가능), **미정** = 아직 안 정함.
> 코드 위치와 개발 요령은 `CLAUDE.md`(핸드오프)를 본다.

## 1. 개요
| 항목 | 내용 |
|---|---|
| 제목 | **HookedSmith** (GBA, Butano 21.8.0 / C++) |
| 한 줄 소개 | 가문의 명예를 위한 대장장이 스미스.. (문구 다듬는 중) |
| 모티브 | 플래시 게임 「검 강화하기」 |
| 목표 | 낡은 단검을 **+29 검**까지 강화한다. +29 달성이 엔딩 (엔딩 화면은 아직 없음) |
| 핵심 루프 | 돈으로 강화 → 성공하면 단계 상승 → 적당한 단계에서 판매해 돈을 번다 → 실패하면 파괴되고 잡템을 얻는다 → 잡템을 방지권·검으로 바꾼다 |

## 2. 모드와 화면 흐름
| 모드 | 상태 | 비고 |
|---|---|---|
| STORY (구 이지) | 선택 가능 | NEW GAME이면 오프닝 컷씬 후 강화 화면. 확률이 높고 재료 요구량이 적다 |
| HARD (구 인피니트) | 잠김 (STORY 클리어 후 해금 예정, 지금은 영구히 잠김) | 컷씬 없음. 엔딩 미정 |
| OPTION | "COMING SOON"만 표시 | 언어 전환 등 예정 |

STORY와 HARD의 차이는 지금 데이터 테이블 차이뿐이다.

화면 흐름: 스플래시(Powered by Butano → JAY'S LOFT 로고) → 타이틀(STORY·HARD·OPTION 아이콘 한 줄, 시간대별 그림) → 시작 화면(NEW GAME / 슬롯 3개) → [STORY NEW GAME만 오프닝 컷씬] → **강화 화면** ⇄ 상점(L) / 화구(R) / 창고(←) / 잡화(↓) / 일시정지(START) / 게임 오버.

## 4. 규칙
| 규칙 | 내용 |
|---|---|
| 화폐 | 정수 달러($) |
| 강화 | 비용을 내고 성공률로 +1. 실패하면 검 파괴 → +0 복귀, 잡템 드랍 |
| 난수 | 0~99를 뽑아 성공률보다 작으면 성공. 시드는 타이틀에서 메뉴를 고른 프레임 수(불러오기는 불러온 프레임 수) |
| 방지권 | 실패했을 때 필요 장수 이상 있으면 쓸지 묻는다. 쓰면 파괴 대신 현재 단계 유지 |
| 판매 | 현재 검을 팔고 +0 복귀. 돈을 버는 유일한 수단. +0은 판매 불가, +28·+29도 판매 불가. **판매 연출**: 검이 번쩍이며 위로 떠올라 흐려지고, 동전이 튀며 소지금이 올라간다. 단계는 성공 연출과 같은 3단계 — +1~5 동전 5개(0.67초) / +6~16 동전 12개 + 금빛 별 + 약한 번쩍임(1초) / +17~28 동전 14개 + 금화 소나기 18개 + 강한 번쩍임(1.5초) |
| 방지권 불가 | 필요 장수 `-`는 저단계라 대상 아님, `불가`는 고단계라 사용 불가. 둘 다 그대로 파괴 |
| 비용 종류 | 돈 / 잡템 / 보관한 검(창고) / 무료 중 하나 (아래 표) |
| 시간대 | 낮 0 / 노을 -2 / 밤 -4%p를 성공률에서 뺀다 (16번) |
| 구제 장치 | 없음. 파산하면 게임 오버 (15번) |

## 11. 강화 화면
### 11-1. 조작
| 기능 | 키 | 동작 |
|---|---|---|
| 강화 | A | 망치 |
| 판매 | B | 지폐 |
| 상점 | L | +0 검일 때만 사용 가능 |
| 화구 | R | +0 검일 때만 사용 가능 |
| 창고 | ← | 보관한 검 목록. A 꺼내기 = 현재 검과 맞바꿈 (현재가 +0이면 버림), R 현재 검 보관 |
| 잡화 | ↓ | 잡템 목록 (보기만) |
| 일시정지 | START | 14번 |
| 도움말 | SELECT | 누르고 있는 버튼의 설명 표시 (켜져 있는 동안은 START 일시정지가 열리지 않는다) |

### 11-2. 정보 배치 (240×160)
- **위쪽 가운데**는 두 줄뿐: 윗줄 **이름**("+N 이름"), 아랫줄 **성공률**. 메시지는 여기에 나오지 않는다.
- **칼 왼쪽**은 **판매가**, **칼 오른쪽**은 **강화비** (각각 이름 줄 + 값 줄, 가운데 맞춤). 재료로 내는 단계(+21~+25, +27)는 강화비 값 줄이 재료(또는 검) 아이콘 + x개수 (예: +21 = +19 검 아이콘 x1, +23 = 악령 혼 아이콘 x12).
- **아래 가운데**는 **메시지 자리** (11-3).
- **왼쪽 아래**는 **최고기록**: `H +27 오딧세이 소드` (H = High). 지금까지 **도달한 가장 높은 단계**이고 판매·파괴해도 남는다 (창고에서 꺼낸 검·워프도 도달로 센다). `H +N`은 이름 줄과 같은 단계 색(+0 회색 / +1~5 흰색 / +6~16 파랑 / +17~ 빨강), 검 이름은 흰색이다. 작은 외곽선 폰트(`hs::font_small`, 10px)를 쓰고, 소지금과 겹칠 만큼 길면 이름을 빼고 `H +N`만 보인다. 망치질·연출 중에는 결과가 새지 않게 이전 값을 유지한다.
- **오른쪽 아래**는 **소지금**: 노란 글자에 주황 외곽선 (상점 오른쪽 위의 소지금도 같다). 1,000 이상은 `$1.3K`·`$2.4M`처럼 줄여 쓴다.
- **아이콘 버튼 6개**(40px, 위치는 바꾸지 않음): 상점(L) 왼쪽 위, 화구(R) 오른쪽 위, 창고(←) 왼쪽, 잡화(↓) 왼쪽 아래, 강화(A) 오른쪽, 판매(B) 오른쪽 아래. 상점·화구는 +0일 때만 컬러, 판매·강화는 못 쓸 때 회색.
- **키 글자 위치**(소지금과 안 겹치게): 화구 **R = 왼쪽 아래**, 강화 **A = 왼쪽 위**, 판매 **B = 왼쪽 위**, 상점 **L = 오른쪽 아래**, 창고 **← = 오른쪽 위**, 잡화 **↓ = 오른쪽 위**.
- **이름 앞 "+N" 색**: +0 회색 / +1~+5 흰색 / +6~+16 파랑 / +17~+29 빨강. 이름 글자는 항상 흰색.
- **결과를 미리 알 수 없게**: 망치질 중에는 이름·판매가·강화비가 강화 전 단계 그대로 보이고, 결과가 나온 뒤에 바뀐다. +29 성공 연출 중에는 폭발 순간(210프레임)까지 +28 값 그대로다 (12-3).

### 11-3. 메시지

## 12. 강화 연출
### 12-1. 성공 (단계가 오를수록 화려해짐)
성공으로 **새로 도달한 단계**에 따라 4가지 (`run_success_effect`, `success_lengths`).
| 도달 단계 | 연출 | 길이 |
|---|---|---|
| +1 ~ +5 (흰색) | 기본: 검이 번쩍이며 살짝 뛰었다 내려온다 | 24프레임 |
| +6 ~ +16 (파랑) | 기본 + **흰 별 8개**가 사방으로 퍼지고, **번쩍임이 한 번 더** 겹친다 | 44 |
| +17 ~ +28 (빨강) | **푸른 별·불씨 22개**가 두 번 터지고 검이 부풀었다 가라앉으며 붉게 빛난다 (화면 번쩍임 없음) | 64 |
| +29 (마지막 검) | **약 6초.** 떨림이 점점 커지고 검이 떠오르며, 금색·빨강 별 고리가 30프레임마다 커지며 퍼지고 화면 번쩍임이 쌓이다가(60·100·140·180) 210프레임에 **화면 하얗게 번쩍 + 별 24개**가 전부 터진다. 이후 황금빛 별이 비처럼 내리고 검이 천천히 내려앉는다. 화면 번쩍임은 여기서만 쓴다 | 360 |

### 12-2. 실패
- 검이 좌우로 떨리다가 **절반쯤(12프레임)에서 오른쪽 위→왼쪽 아래로 지그재그 금이 가고 번쩍인다** (빠직). 떨림은 24프레임.
- **방지권을 쓰는 경우:** 금 간 검 그대로 질문이 뜨고, A(예)를 누르면 금이 사라지며 번쩍이고(16프레임) 원래 검으로 돌아온다. "복구 했다!"
- **부서지는 경우(방지권 없음 또는 안 씀):** 금 간 선을 따라 **두 동강**이 나 위쪽 조각은 왼쪽 위로, 아래쪽 조각은 아래로 돌며 떨어지고(36프레임) **파편 4개**가 튄다. 그 뒤 +0 검과, 잡템이 있으면 파괴 메시지가 나온다.

### 12-3. +28 → +29 실패: 낚시 연출 (약 6.5초)
+28에서 강화에 실패하면(성공률 15%) 일반 실패 연출 대신 **성공처럼 보이게 속이다가 바스러진다.** 결과 메시지는 일부러 숨긴다.
1. **쌓임 (0~222프레임):** +29 성공 연출과 **똑같다** (같은 코드 `grand_buildup`): 떨림, 떠오름, 금·빨강 별 고리, 쌓이는 번쩍임, 210프레임의 눈부신 폭발까지. 이름·성공률·검 그림·강화비·판매가도 +28 값 그대로.
2. **정적 (222~262):** 빛이 뚝 꺼지고 별이 사라진다. 검은 금이 간 채 **잿빛**으로 멎고 화면이 서서히 어두워진다.
3. **바스락 (262~392):** "강화 실패.." 메시지와 함께 재가 계속 날리고, 검이 천천히 낮아지며 투명해져 사라진다. 이어서 +0 검.
방지권은 +28에서 쓸 수 없다 (기존 규칙).
소리: 땅땅(망치질) 뒤 쌓임이 시작되는 프레임부터 +29 성공과 같은 "빛이 차오르는" 소리(`sfx_glow`, 3.45초)가 나고, 빛이 꺼지기 3프레임 전에 "빠직"이 이어진다 (+29 성공이면 이 자리에 성공음). 배경음은 쌓임이 시작될 때 잦아들기 시작하고 빛이 꺼질 때 끊긴다.

### 12-4. 구현 메모
- 검 그림은 `tools/make_swords.py`가 프레임 4개(원래·금·위 조각·아래 조각)로 자동 생성한다 (검 그림을 바꿔도 따라감). 별 4색·파편·가루 3종은 `graphics/fx.bmp` 한 장의 프레임이다 (팔레트를 하나만 쓰려고 합쳤다).
- 디버그 빌드의 R(무조건 실패/성공/끔)·L(단계 점프) 키로 연출을 바로 볼 수 있다 (`CLAUDE.md`).

## 13. 목록 화면 (상점·화구·창고·잡화)
이름·결과 앞에 16×16 아이콘(그림은 14×14, 가장자리 투명)이 붙고, 각 화면은 흑백(15단계 회색)으로 어둡게 줄인 그림을 배경으로 쓴다. 아이콘마다 자기 15색 팔레트를 쓴다 (목록 화면에는 팔레트가 남는다).
| 화면 | 아이콘 | 배경 |
|---|---|---|
| 상점 | 방지권(1장·3장 같은 그림), 워프권(+9·+13·+14·+15 같은 그림, 단계는 글자) | 가게 주인 카운터 |
| 화구 | 왼쪽 재료 8종, 오른쪽 결과: 방지권 아이콘 + "x개수" / 검 아이콘 + "+단계" | 화로 |
| 창고 | 보관한 검마다 그 검의 아이콘 (30종) | 검 진열대 |
| 잡화 | 잡템 8종 | 자루 |
- 돈은 아이콘 없이 `$` 글자 그대로.
- 잡템 아이콘 10개(방지권·워프권 포함): `assets/graphics/items/item_icons_source.webp`를 줄인 것 + 직접 그린 4개(낡은 고철, 불꽃 자루=칼날이 불꽃인 손잡이, 악령 혼=해골, 도끼 가루). `python -B tools/make_item_icons.py --write`.

- 배경: 원본 `assets/graphics/menu_bg/menu_backgrounds_source.png`(2×2). `python -B tools/make_menu_bgs.py`. 밝기 `BRIGHTNESS` 0.72, 제목·안내 줄 자리는 더 어둡게.
- 알려진 아쉬움: 어두운 검(+3, +12, +13, +15 등)은 검은 배경에서 대비가 약하다.

## 14. 일시정지와 세이브
### 14-1. 일시정지 (START, 강화 화면에서만)
| 항목 | 동작 |
|---|---|
| PAUSE | 제목 글자. 고정 |
| Resume | 게임을 재개한다 (START·B로도) |
| Save | 슬롯 3개 중 선택해 저장. 이미 저장된 슬롯은 "덮어쓸까요? A 예 B 아니오"로 한 번 묻는다 |
| Quit | 메인 타이틀로 돌아간다 (저장 안 한 진행 경고는 없음) |
- Resume / Save / Quit은 ↑↓로 고르고, 고른 줄이 위아래로 흔들린다.
- 모양: 강화 화면 배경을 흑백으로 어둡게 깔고 모루만 올린다. 글자는 흰색 + 검은 외곽선(`hs::font_outline`).
- 아직: 상점·화구·창고·컷씬에서는 START가 동작하지 않는다.

### 14-2. 세이브 (SRAM 슬롯 3개)
- **저장 항목:** 난이도, 소지금, 현재 검 단계, 최고기록(도달한 가장 높은 단계; 예전 저장은 이 자리가 0이라 현재 단계가 최고기록이 된다), 방지권, 잡템 8종, 보관한 검(최대 8). 난수 시드와 시간대는 저장하지 않는다 (16번).
- **공통 머리글:** HARD 해금 플래그 (`hs::save::hard_unlocked()`, 해금은 엔딩에서 `unlock_hard()`로).
- **안전장치:** 슬롯마다 검사합과 값 검사가 있어서 깨지거나 처음 쓰는 카트리지의 슬롯은 빈 슬롯으로 본다. SRAM 32KB 중 약 200바이트를 쓴다.
- **불러오기 = 시작 화면:** 타이틀에서 STORY 또는 HARD를 고르면 "NEW GAME"과 슬롯 3개(예: `SLOT 1  STORY +3  $9.9K`, 빈 슬롯은 "비어 있음")가 나온다. NEW GAME이면 새 게임(STORY만 오프닝 컷씬 후 시작, HARD는 바로 시작), 슬롯을 고르면 컷씬 없이 바로 강화 화면. 빈 슬롯은 "비어 있는 슬롯이다". B는 타이틀로. 어떤 모드의 슬롯이든 불러온다 (미정: 모드별로 나눌지).
- 아직: 슬롯 삭제, 언어 저장, 자동 저장.

## 15. 게임 오버 (파산)
파산 구제 장치는 **없다.** 아무것도 할 수 없는 상태가 되면 게임 오버. 파산 조건 (아래를 **모두** 만족할 때):
| 조건 | 설명 |
|---|---|
| 강화할 수 없음 | 돈이 현재 단계의 강화비보다 적다 (+0이면 STORY $3 / HARD $5). 재료 강화 단계는 재료가 없다 |
| 상점에서 살 수 없음 | 돈이 가장 싼 상품(워프 +9 HARD $8,000 / 방지권 STORY $10,000 등)보다 적다 |
| 화구에서 만들 수 없음 | 어떤 교환도 잡템 수량이 모자란다 |
| 팔 것이 없음 | 지금 검이 +0이고 창고에도 검이 없다 (검이 있으면 팔아서 돈을 만들 수 있다) |
- 판정은 강화 화면이 평상시일 때 하고, 판매·파괴 결과 메시지를 다 보여 준 뒤 게임 오버로 넘어간다. 상점·화구·창고에서 돌아와도 같다. 최종 검(+29)은 파산이 아니다. 방지권이 남아 있어도 위 조건이면 파산이다.
- 화면: 일러스트(대장간 앞에 무릎 꿇은 스미스, GAME OVER 간판이 그림 안에 있음)와 깜빡이는 "아무 버튼이나 누르세요". 처음 약 0.75초는 입력을 받지 않는다. 아무 버튼을 누르면 타이틀로 간다. 그림: `assets/graphics/gameover/gameover_source.jpg` → `tools/make_gameover.py`.
- **저장 슬롯은 건드리지 않는다** (마지막 저장부터 다시 불러올 수 있다). 게임 오버 전용 음악·효과음은 아직 없다.
- 디버그 빌드: B를 누른 채 ↑로 파산 상태를 만든다.

## 16. 시간대 (RTC)
카트리지 RTC 시계로 하루를 셋으로 나눈다. 시계가 없거나 읽지 못하면 **낮**(보정 없음).
| 시간대 | 시각 | 타이틀 그림 | 강화 성공률 보정 |
|---|---|---|---|
| 낮 | 06~16시 | 낮 | 원작 그대로 (0%p) |
| 노을 | 16~21시 | 노을 | -2%p |
| 밤 | 21~06시 | 밤 | -4%p |
- 보정은 **강화 성공률만** 바꾼다 (판매가·비용·방지권은 그대로). **100% 구간에도 적용** (예: 노을에 +0은 98%), **하한 0%**, **HARD에도 같은 값**.
- 강화 버튼을 누르는 순간 시계를 읽고, 강화 화면에서는 1초마다 확인해 16시·21시·06시를 넘으면 성공률 표시가 바로 바뀐다. 화면의 "성공률 N%"는 보정된 값이다 (시간대 자체를 알려 주는 표시는 아직 없다).
- **세이브와의 관계:** 시간대는 저장하지 않는다. 낮에 저장한 것을 밤에 불러오면 밤 확률이 적용된다.
- 플레이어가 시계를 바꿔 시간대를 고르는 것은 **허용** (막지 않는다).
- 구현: `include/time_band.h` / `src/time_band.cpp`(`hs::current_time_band()`), 보정은 `economy::success_pct()`. 실제 카트리지에 RTC 칩이 있어야 한다 (mGBA는 `[override.HKSM] hardware=1`).
- 엔딩 연출도 이 시간대(낮/노을/밤)에 따라 다르게 할 예정 (17번).

## 17. 스토리와 이름
- 왕이 "+29 검 = 평생 세금 면제" 포고문을 건다. 오프닝 컷씬은 4장면(아버지의 유언): `src/main.cpp`의 `opening_scenes`.
- 랜덤 이벤트(도둑, 세금 징수관, 수상한 상인, 고양이, 라이벌 대장장이)는 나중에.
- 엔딩(기획): 왕이 너무 무거운 +29 검에 깔리고, 마을 사람들이 냄비와 괭이를 들고 "우리 것도 +29 해주게" 줄을 서며, 마지막에 타이틀. **시나리오는 추후 기획**, 플레이 시각의 시간대(낮/노을/밤)에 따라 연출을 다르게 한다. 하드 엔딩은 미정.
- 진행 구간(임시): +0~5 동네 대장간 / +6~10 소문 / +11~15 왕의 눈 / +16~20 전설 / +21~29 재료 강화.
- **검 이름 정책 (확정):** 일단 원작 한글 이름을 쓴다 (`sword_names`). 나중에 고치더라도 지금은 그대로. 오리지널 이름으로 교체할지는 배포 전에 다시 판단.

## 17-2. 고양이 이벤트 (보은)
- **발생**: 새 게임(또는 목표가 없는 예전 저장)을 시작할 때 목표 횟수를 **26 / 30 / 62** 중 무작위로 정한다. 강화에 **실패할 때마다**(방지권으로 막은 실패와 파괴된 실패 모두) 횟수를 세고, 목표에 닿으면 고양이가 나온다. 고양이가 다녀가면 횟수를 0으로 되돌리고 목표를 다시 뽑는다. STORY·HARD 공통, 세이브에 저장한다 (슬롯의 `cat_state` 한 바이트: 아래 6비트 횟수 + 위 2비트 목표 번호). 디버그 빌드는 바로 확인하도록 목표가 2·3·4번이다 (`cat_targets`).
- **시점**: 실패 결과(금 가는 연출·파괴 메시지·방지권 질문)가 끝나고 강화 화면이 평상시(IDLE)로 돌아와 메시지가 사라진 뒤. **파산 판정보다 먼저**라서 선물이 구제가 될 수 있다. +28 낚시 연출 뒤에도 같다.
- **연출** (`run_cat_event`, 약 7초): 강화 배경 위에 정가운데 창(86x70)이 열리며 이벤트 알림음(`sfx_event`, 반짝) → 고양이가 창 안 왼쪽에서 스르륵 나타나 걷고 앉아 꼬리를 흔든다 → 같은 창에 고양이 사진이 번쩍이며 나오고 `sfx_cat`(야옹 야옹) → 창 아래 메시지 → A로 끝낼 수 있다. 장면 음악 `bgm_event_cat`(총총, 바장조 120BPM)이 흐르다 끝날 때 잦아든다. 장면 동안 강화 화면 배경음은 끊는다.
- **메시지**: 1단계 "귀여운 고양이가 / 뭔가를 물어왔다!" → 2단계 "+N 검 이름 / 창고로 들어갔다". 창고가 가득 차면 "방지권 3장을 / 받았다".
- **선물**: +17, +18, +20, +21 검 중 하나를 무작위로 창고에 넣는다. 창고가 가득 차면 방지권 3장 (`cat_gift_levels`, `cat_gift_tickets`).
- **그림**: 도트 고양이 `graphics/cat.bmp`(32x32 x 7장, 걷기 4 + 앉아 꼬리 3), 창 틀 + 방 `cat_room.bmp`, 창 틀 + 사진 `cat_photo.bmp` (원본 사진은 `assets/graphics/events/cat_source.webp`). 모두 `tools/make_cat_assets.py`로 다시 만든다 (시안 스크립트: `make_cat_sprite.py`, `make_cat.py`, `make_cat_event_mock.py`, `preview_cat_audio.py`).
- **이벤트 틀**: `sfx_event`는 다른 이벤트(도둑·세금 징수관 등)도 같이 쓰는 "이벤트 발생" 알림음이다.
