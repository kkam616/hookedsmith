# HookedSmith 게임 매뉴얼 (역기획 문서)

> 구현된 시스템을 기준으로 정리한 문서다. 시스템을 추가하거나 고칠 때 같이 고친다.
> `<!-- AUTO:... -->` 안의 표는 `python tools/make_manual.py`가 `include/economy_data.h`에서 다시 만든다. 표를 손으로 고치지 말고 데이터 파일을 고친 뒤 스크립트를 돌린다.
> 상태 표기: **확정** = 원작·기획으로 정해진 값, **임시** = 내가 정한 값(조정 가능), **미정** = 아직 안 정함.

## 1. 개요
| 항목 | 내용 |
|---|---|
| 제목 | **HookedSmith** (GBA, Butano 21.8.0 / C++) |
| 한 줄 소개 | 가문의 명예를 위한 대장장이 스미스.. (문구 다듬는 중) |
| 모티브 | 플래시 게임 「검 강화하기」 |
| 목표 | 낡은 단검을 **+29 검**까지 강화한다. +29 달성이 엔딩 (엔딩 연출은 아직 없음) |
| 핵심 루프 | 돈으로 강화 → 성공하면 단계 상승 → 적당한 단계에서 판매해 돈을 번다 → 실패하면 파괴되고 잡템을 얻는다 → 잡템을 방지권·검으로 바꾼다 |
| 화면 흐름 | 스플래시 → 타이틀 → 강화 화면 ⇄ 상점(L) / 화구(R) / 창고(←) / 잡화(↓) |

## 2. 모드
| 모드 | 상태 | 시작 소지금 | 비고 |
|---|---|---|---|
| STORY (구 이지) | 선택 가능 | 아래 3번 표 | 오프닝 컷씬 후 강화 화면. 확률이 높고 재료 요구량이 적다 |
| HARD (구 인피니트) | 잠김 (STORY 클리어 후 해금 예정) | 아래 3번 표 | 컷씬 없음. 엔딩 미정 |
| OPTION | "COMING SOON"만 표시 | - | 언어 전환 등 예정 |

STORY와 HARD의 차이는 지금 데이터 테이블 차이뿐이다.

## 4. 규칙
| 규칙 | 내용 |
|---|---|
| 화폐 | 정수 달러($) |
| 강화 | 비용을 내고 성공률로 +1. 실패하면 검 파괴 → +0 복귀, 잡템 드랍 |
| 난수 | 0~99를 뽑아 성공률보다 작으면 성공. 시드는 타이틀에서 메뉴를 고른 프레임 수 |
| 방지권 | 실패했을 때 필요 장수 이상 있으면 쓸지 묻는다. 쓰면 파괴 대신 현재 단계 유지 |
| 판매 | 현재 검을 팔고 +0 복귀. 돈을 버는 유일한 수단. +0은 판매 버튼 없음, +28은 판매 불가 |
| 방지권 불가 | 필요 장수 `-`는 저단계라 대상 아님, `불가`는 고단계라 사용 불가. 둘 다 그대로 파괴 |
| 비용 종류 | 돈 / 잡템 / 보관한 검(창고) / 무료 중 하나 (아래 표) |
| 구제 장치 | 없음. +0인데 돈이 모자라면 그대로 막힌다 (게임 오버 이벤트 예정) |

## 12. 스토리 (기획)
- 왕이 "+29 검 = 평생 세금 면제" 포고문을 건다.
- 랜덤 이벤트(도둑, 세금 징수관, 수상한 상인, 고양이, 라이벌 대장장이)는 4단계 이후.
- 엔딩: 왕이 너무 무거운 +29 검에 깔리고, 마을 사람들이 냄비와 괭이를 들고 "우리 것도 +29 해주게" 줄을 서며, 마지막에 타이틀.
- 진행 구간(임시): +0~5 동네 대장간 / +6~10 소문 / +11~15 왕의 눈 / +16~20 전설 / +21~29 재료 강화.
- 오프닝 컷씬: `src/main.cpp`의 `opening_scenes`. 하드 엔딩은 미정.

## 13. 검 이름 정책 (확정)
- 일단 원작 한글 이름을 쓴다 (`sword_names`). 나중에 고치더라도 지금은 그대로 사용.
- 오리지널 이름으로 교체할지는 배포 전에 다시 판단. (2026-10-16 결정, 기존 "원작 이름 금지" 문구는 삭제)
