## 스토리
- 왕이 "+29 검 = 평생 세금 면제" 포고문을 건다. 랜덤 이벤트: 도둑, 세금 징수관, 수상한 상인, 고양이, 라이벌 대장장이.
- 엔딩: 왕이 너무 무거운 +29 검에 깔리고, 마을 사람들이 냄비와 괭이를 들고 "우리 것도 +29 해주게" 줄을 서며, 마지막에 Hooked Smith 타이틀.
- 진행 구간(임시, +29 기준으로 다시 나눌 것): +0~5 동네 대장간 / +6~10 소문 / +11~15 왕의 눈 / +16~20 전설 / +21~29 재료 강화.
- 하드 모드 엔딩은 미정.

## 데이터 취급 원칙
- 원작 참고 데이터는 검증되지 않은 값이다. 빠진 확률·비용·레시피를 조용히 지어내지 말고 가정은 가정이라고 표시한다.
- 검 이름은 일단 원작 한글 이름을 쓴다(결정: 나중에 고치더라도 지금은 사용). 오리지널 이름 교체는 배포 전에 다시 판단.
- 후반 레시피 재료(악마의 영혼, 도끼 가루, 투명한 물질)는 방지권 교환에 쓰기 전에 먼저 확보한다.
- 밸런스를 바꾸기 전에 영향받는 가격·비용·확률·조합 요건을 먼저 파악한다.
- 금액은 정수 달러(`$`), `int32_t`, 소지금 상한 클램프. 원작 원화 ÷100은 스펙에 이미 반영됨 — 단계·확률·수량에는 ÷100 금지.

## 미정
- 시작 자금: 스토리 $10,000 / 하드 $20,000 (원작 100만원·200만원 ÷ 100, `start_money_easy`·`start_money_hard`).
- 워프 성공 확률(임시 50%), 실패 시 잡템 드랍 수(임시 0~5개, 확률 10/25/30/20/10/5%, 평균 약 2.1)
- 검 이름 목록, BGM(마지막에 OpenMPT .xm + MaxMod), 시간대 타이틀 경계(지금 낮 6~14 / 노을 14~22 / 밤 22~6)
- 랜덤 이벤트, RTC 기반 연출, 사운드는 4단계 이후.
- 강화비가 없는 상황(+0인데 돈이 모자람)은 게임 오버 이벤트로 처리할 예정. 지금은 구제 장치 없이 그대로 막힌다.
