# 랜덤 이벤트 3종: 컷 구성표 (GIF 제작용)

고양이 / 도둑 / 수상한 상인 이벤트를 실제 게임(디버그 ROM, 창 캡처 약 22fps)에서 녹화한 GIF와, 같은 장면을 새 그림으로 만들 때 필요한 컷 구성입니다.
- 녹화 GIF: `docs/event_gifs/cat.gif`, `thief.gif`, `merchant.gif` (240x160 원본). 3배 확대본(`*_x3.gif`)은 용량이 커서 저장소 밖(`build/`)에 둔다.
- 컷 시트: `docs/event_gifs/*_storyboard.png` (이벤트를 일정 간격으로 12컷, 시간 표시 포함).
- 녹화 도구: `tools/record_helper.ps1`(창 녹화 + 키 일정), `tools/make_event_gifs.py`(GIF), `tools/find_event_span.py`(이벤트 구간 찾기), `tools/make_event_storyboards.py`(컷 시트).
- 녹화에 쓴 ROM은 디버그라 왼쪽 위에 `T 사용/최고` 타일 카운터가 보이는 컷이 있다 (이벤트 화면 안에는 없다).

## 공통 규격 (세 이벤트가 같은 틀)
| 항목 | 값 |
|---|---|
| 화면 | 240x160, 강화 화면 배경 위에 **가운데 창**이 열린다 |
| 창 | 안쪽 **80x64**, 틀 포함 **86x70**, 화면 왼쪽 위 (77, 41) |
| 방 그림 | 창 안쪽 80x64, 4bpp **15색 + 투명(0번)**, 틀은 만드는 스크립트가 붙임 |
| 사진 | 창 안쪽 80x64, 15색 (AI 일러스트를 줄여서 사용) |
| 스프라이트 | **32x32** 프레임을 세로로 이어 붙인 시트, 15색 + 투명(마젠타 255,0,255) |
| 진행 | A로 페이지를 넘긴다: ① 모션 장면 → ② 사진 + 첫 메시지 → ③ 같은 사진 + 두 번째 메시지 → 끝 |
| 번쩍임 | 이벤트 시작과 사진이 나올 때 흰색 번쩍임 (약 8프레임) |
| ▼ | 메시지가 읽힌 뒤 20프레임마다 깜빡이며 A를 기다린다 |
| 시간 | 1프레임 = 약 16.7ms (60fps). GIF 프레임 시간은 아래 "프레임"을 ×16.7ms로 환산 |

## 1. 고양이 (강화 실패가 목표 횟수에 닿을 때, 시간대 무관)
녹화: `docs/event_gifs/cat.gif`
| 컷 | 내용 | 그림 | 길이(프레임) |
|---|---|---|---|
| C1 | 알림 번쩍 + 방 창이 열림 (빈 어두운 방) | 방 배경 `cat_room` | 약 24 |
| C2 | 고양이가 왼쪽에서 걸어 들어옴 (페이드 인) | 스프라이트 걷기 8프레임, 20프레임에 한 바퀴 | 44 |
| C3 | 가운데에 앉아 **꼬리를 계속 흔듦** + ▼ | 스프라이트 앉기 3프레임 (처음 10프레임은 둘째 자세, 이후 8프레임마다 순환) | A 누를 때까지 |
| C4 | A → **야옹 소리와 사진**이 번쩍이며 나옴 + 첫 메시지 | 사진 `cat_photo` | 14프레임 뒤 메시지 |
| C5 | A → 같은 사진 + 두 번째 메시지(선물 안내) | (같은 사진) | A 누를 때까지 |

## 새 그림을 만들 때 필요한 것 (이벤트마다)
| 이벤트 | 스프라이트 프레임 (32x32) | 방 배경 (80x64) | 사진 (80x64) |
|---|---|---|---|
| 고양이 | 걷기 8 + 앉아 꼬리 흔들기 8 = **16** | 1장 | 1장 |
| 도둑 | 걷기 8 + 서 있음 2 + 집기 1 + 검 들기 2 = **13** | 3장 (검 / 금화 / 빈 방) | 1장 |
| 상인 | 걷기 10 + 서 있음(살핌 겸용) 1 + 돈뭉치 내려놓기 6 = **17** | 2장 (빈 받침대 / 금화 더미) | 1장 |

- 걷기 프레임은 **오른쪽을 보는 옆모습**이고 왼쪽을 볼 때는 코드에서 좌우 반전한다.
- 스프라이트와 방은 15색을 넘기면 안 된다 (넘으면 변환이 거칠어진다). 사진은 AI 일러스트를 그대로 주면 80x64, 15색으로 줄여 준다.
- 변환 스크립트: `tools/make_cat_assets.py`, `make_thief_assets.py`, `make_merchant_assets.py`. 원본 파일은 `assets/graphics/events/`.
